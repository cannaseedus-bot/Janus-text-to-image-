# WAD Files Directory

This directory is for **your legally obtained WAD files**.

## 🎮 How to Get WAD Files (Legally)

### Option 1: Buy DOOM ($4.99)
Purchase from:
- **Steam**: https://store.steampowered.com/app/2280/DOOM/
- **GOG**: https://www.gog.com/game/the_ultimate_doom
- **Epic Games**: Occasionally free

After purchase, find DOOM.WAD in:
- Windows: `C:\Program Files (x86)\Steam\steamapps\common\Ultimate Doom\base\DOOM.WAD`
- Mac: `~/Library/Application Support/Steam/steamapps/common/Ultimate Doom/base/DOOM.WAD`
- Linux: `~/.steam/steam/steamapps/common/Ultimate Doom/base/DOOM.WAD`

Copy it here: `wads/DOOM.WAD`

### Option 2: Download Freedoom (FREE)
100% legal, open-source replacement:

```bash
# Run from project root
./download-freedoom.sh
```

This downloads:
- `freedoom1.wad` (DOOM 1 replacement)
- `freedoom2.wad` (DOOM 2 replacement)

### Option 3: Shareware DOOM (FREE)
The shareware version is legally distributable:

```bash
wget http://distro.ibiblio.org/slitaz/sources/packages/d/doom1.wad
mv doom1.wad wads/
```
